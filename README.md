# Gurukul AI website

Public product website for Gurukul AI, a Marathi-first AI learning companion being developed for Standards 9 and 10 in Maharashtra.

## Run locally

```powershell
npm.cmd ci
npm.cmd run dev
```

Open `http://127.0.0.1:5173/`.

## Production build

```powershell
npm.cmd run build
```

## Public trust pages

- `/privacy`
- `/terms`
- `/responsible-ai`
- `/security`
- `/accessibility`

The site deliberately labels planned controls, scale targets, and audits as roadmap commitments rather than completed certifications.
